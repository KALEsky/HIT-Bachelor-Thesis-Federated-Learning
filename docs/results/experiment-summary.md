# Experiment result notes

The numeric summary in the main README follows the final thesis discussion.
The figures are selected from the historical experiment outputs rather than
generated again during repository preparation.

The strong-attack comparison uses attack probability `1` for both the FGSM and
label-poisoning clients. The thesis compares reputation adjustment factors `0`,
`3`, `5`, and `7`; the factor-5 configuration is discussed as the best balance
between final accuracy and early convergence.

The original console logs were not copied because they contain local executable
paths and several exploratory runs. They remain in the original working folder,
not in this public repository.
